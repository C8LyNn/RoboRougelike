## What the asset does in Unity

[`Unity/Editor/B0124EnemyStageBuilder.cs`](Unity/Editor/B0124EnemyStageBuilder.cs) + [stable tracked `.meta`](Unity/Editor/B0124EnemyStageBuilder.cs.meta) are ready to import **only after explicit Codex acceptance** into a new isolated `Assets/Editor/B0124EnemyStagingW03/` path.

In the Unity 6000.3.14f1 editor, use:

**B01 → Enemy Staging → Generate all 12 isolated formation scenes**

The tool calls original Unity `GameObject.CreatePrimitive` for a floor, correct source-derived `R5Arena.Build` walls and cover objects, player spawn, 2 hazard marker positions, and **1–4 enemy body-width proxy cylinders (5m diameter)**. It includes a top-down camera and directional light, then uses `EditorSceneManager.SaveScene` to create 12 scenes in **`Assets/B0124EnemyStagingW03/Scenes/`**. These may be opened in Unity and inspected, tested with native collider checks, or compared visually; no runtime integration, R6 physics or actual enemy AI is attached.

**Importantly:** it creates scenes **additively**, makes only the temporary staging scene active, and closes *only that temporary scene* in a `finally` block, returning to the receiver's original active scene. It preflights all 12 destination names and **refuses every overwrite**, including files previously generated by this tool; if files exist, use a fresh disposable checkout or explicitly move/backup those files first. It never resets an unrelated open scene or modifies Codex's original `Assets/R5/R5Arena.cs`, `R1EncounterManager`, `main` or `develop`.

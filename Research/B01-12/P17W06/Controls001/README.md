## Working feature

Open `controls.html` directly in Chromium without server/network. Two isolated contexts (*Walka i jazda* and *Garaż*) expose 13 real, interactive action rows; remap supported keyboard codes by clicking or keyboard-activating *Zmień*. A same-context collision requires explicit atomic swap or cancel; duplicate keys in different contexts are permitted. LMB and RMB are immutable in this **research profile**, avoiding any claim to alter Codex's weapon control. Undo/Redo have bounded 40-step history, reset returns defaults, Escape cancels capture, invalid/browser/system shortcuts do not change state. JSON export is versioned/deterministic and is invalidated when state changes; strict JSON import validates complete exact action identities, reserved mouse controls, supported codes, and no same-context collisions before atomic commit. UI uses live status and focusable controls at phone/tablet/desktop viewports. **No writes** to Unity `Assets/**`, Input System, saves, browser storage, or Codex runtime.

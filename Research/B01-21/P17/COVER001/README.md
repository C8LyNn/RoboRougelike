## Functional sources / reproducible output

`cover_field.py` consumes the **actual original MAPGEN C# generated source blueprints** (P16) through unchanged `map_routes.load_original` (P17), with fail-closed original Git blob pinning and original `geometryHash`. For each original 64×64m CombatArena (6, 11, 16 real Cover boxes):

1. Generate **source-clear exposure field** on a 4m XZ grid. An eligible cell needs original floor support and a conservative historical Heavy body AABB clearance against the original source `Boundary` and `Cover` geometry plus 0.25m. Each point stores **which of the three original enemy-spawn descriptors** have static LOS at eye height Y=1.25m, and which are shielded. Covers count as blockers **only when their original 3D box extends through that eye height**. All generated coordinates remain in original MAPGEN **local XZ**.
2. For every source Cover, test four offset cardinal **anchor candidates** outside the historical Heavy envelope. Include a point **only if the associated original source Cover itself** blocks at least one original enemy-spawn sightline, the point is source-floor/AABB clear, the original-source P17 A* path from actual `Start=(0,-25)` reaches it, and no other selected Cover already claimed the same grid position. If no valid self-occluding anchor is found, **that Cover receives no anchor**. Do not make artificial enemy AI/loot spawn choices.
3. Produce **three real compact machine-readable JSON fields**, **three actual top-down SVG source-geometry previews** (heatmap 0..3 visible descriptors, original blockers, enemy-source markers and accepted yellow anchors), and `generated/manifest.json`. The generator is deterministic; generated bytes must be reproducible.
4. **Negative tests:** original source hash mutated, unknown obstacle type, rotated box not represented by AABB, absent original Floor, altered count of source enemy descriptors, too-low box mistaken for occlusion; all fail closed or establish visibly correct negative prediction.

Files: `cover_field.py`, `test_cover_field.py`, `generated/*.cover.json`, `generated/*.cover.svg`, `generated/manifest.json`, `INSTALL_FOR_CODEX.md`, dedicated Windows/Ubuntu workflow.

**Strict limitations:**
- Source-only immutable geometry, 4m grid samples, static 1.25m LOS **proxy**; this does **not** perform actual Unity Physics.Raycast/mesh colliders, URP rendering/shadows, dynamic damaged cover, projectile/sensor layers, obstacle movement or camera occlusion.

# COURSE-MAPDOC-001 / B01-20 PASS17 W03

**Production:** Generates 18 real, native-format MapDocument v2 JSON files (3 original MAPGEN ObstacleCourse variants × 6 seeds). Original MAPGEN source PR #237 SHA 5be31039411f89f17654b1c332f8692883fa03cc, original P17 generator PR #331 SHA 07d7d271b11ffc70e8e09da0043559fba06b5868. New work is distinct from the browser arcade viewer #365 and two B01-25 maps #392.

Each course is generated by the ORIGINAL immutable MapGenPlanner C#, rasterized by convert.py onto an integer 1m grid and moved into native editor ±50 coordinates. Floor maps to Ground, Boundary→Wall, Obstacle→Obstacle, Ramp→Ramp. Native editor Spawn and Finish are real MapItemKind entries. Exact original checkpoints (3-5) remain in separate *NON-NATIVE* checkpoint-sidecar JSON files because Codex MapDraft has NO checkpoint kind. A BFS prevents the conversion from blocking their rasterized 2D corridor.

**Provenance / real compiler acceptance:** the QA project compiles the original unchanged Codex Assets/MapEditor/MapDraft.cs from PR #310 commit be2c4b6ac63e04eff5b046e50641ec8d1da4837f, exact Git blob 0331a54a1545ecd1ea18b616ef13fed113474b8c, using isolated .NET8 UnityEngine/JsonUtility stubs. Validates every generated MapDocument with original MapDraft.TryLoad, TestError and ToJson roundtrip, negative malformed maps and SHA receipt. DO NOT confuse stub with Unity native JsonUtility, EditMode, PlayMode or PhysX. Native remains NOT_RUN.

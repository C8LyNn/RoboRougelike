# B01-11 / PASS17 WAVE10 — UXVIEWPORT-001 R1 — responsive tactical HUD geometry

**New functioning original pure C# layout engine**, not an HTML-only UX prototype, spreadsheet, report, or duplicated keyboard-focus/hint/combat-feed selector. `Runtime/HudLayoutCore.cs` computes pixel-space rectangles for: Critical alerts, player vitals, threats, optional objectives, optional help/tips, Pause button. It is game-integratable source with no UnityEngine dependency. NO actual Codex Unity UI has been changed, and the source is not currently game-integrated.

## What it does
- Based on **real source inspection**: the current R1 IMGUI HUD at `Assets/R1/R1RunHUD.cs`, inspected historical source blob `049266e930fcb27062c0425dda248a970b681923` from gameplay commit `203a0805251ed28293888e43f2d49f0df63767c6`, uses a fixed 1280×720 virtual canvas and screen-scaled GUI matrix. This is a layout **proposal and executable implementation** to improve narrow/portrait and overscan UX, NOT a claim that this existing HUD has adopted it.
- `HudLayoutCore.Build(HudViewport)` yields immutable geometry in **top-left pixel coordinates**. Portrait and narrow displays use a critical-first stack, landscape >=980px safe width and sufficient aspect uses two columns. Mandatory **Critical, Vitals, Threats, Pause** remain present, safe-contained and non-overlapping. Optional objectives/tips are omitted if space is unavailable. Explicit `InvalidOperationException` if mandatory rects cannot fit, rather than silently clipping/overlapping.
- Accepts safe-area insets on all four edges, accommodates viewport 320×568 through 4K, user text scale 100/125/150% and deterministic pixel rounding. Layout has no screen/device queries, timer, network, input interception, save/gameplay changes or VFX.
- Strict checks on viewport dimensions 320–16384px width and 420–16384px height, insets and effective minimum safe area. `HudLayout.VisiblePanels()` returns an independent array, and `HudRect.Contains/Intersects` support easy layout QA.
- Exactly **75 executed original C# assertions per OS**, including eight specified resolutions ×3 user text scales, safe-area clipping, portrait/4:3/wide geometry, mandatory/optional visibility, font scale, invalid small viewports, overlap, deterministic outputs and negative input cases. [Actual original-source cross-platform Actions #41065292153 SUCCESS](https://github.com/C8LyNn/RoboRougelike/actions/runs/41065292153): **75/75 Ubuntu +75/75 Windows**, 150/150, zero FAIL; repeat on frozen complete HEAD after documents.

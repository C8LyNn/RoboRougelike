## W17 / R2 mandatory run-reset motor-stop integration boundary

When a future **Codex-owned authorized** Unity Input System gamepad driver transitions gameplay run IDs, it MUST capture and consume `bool stopExistingMotors = gate.StartNewRun(nextRunId)`. The gate has no actual hardware handle and cannot stop anything by itself.

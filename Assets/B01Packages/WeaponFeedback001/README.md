## P17 W34 corrective receipt — nonfinite source values cannot poison Unity VFX
Observed in prior exact Unity source: `Mathf.Clamp01(float.NaN)` can preserve NaN, which then propagates into the ParticleSystem damage-smoke rate. The prior `NotifyImpact` also created a world-space ParticleSystem for NaN/Infinity positions or nonfinite/overflowed surface normals. These are source-visible correctness hazards, not proven runtime crashes.

**Product fix on existing #878:** private finite checks reject invalid `NotifyImpact` world position before counting the visual event or allocating a particle. Invalid normal components or an overflowed normal magnitude fall back to `Vector3.up`; the valid impact still plays. `SetWeaponDamageVisual` converts any nonfinite incoming float (NaN/positive Infinity/negative Infinity) into **visual fraction 0** and disables emission; valid finite fractions retain existing `Clamp01` semantics. No changes to authoritative weapon damage/HP/event emission, economy, Save, prefab GUIDs or scene.

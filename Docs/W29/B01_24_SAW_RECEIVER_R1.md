## W32 physical enemy saw bugfix: SIGNED forward mount clearance
The real RRLSawBinding.PlaceEnemySawBeyondHull implementation used the **magnitude** of muzzle offset to decide clearance in `Enemy_Yaw.forward`. This loses the sign. If imported muzzle is behind the pivot (e.g. negative Z from a mismatched FBX transform), the helper can move forward too little and leave the rotor inside owned chassis collider geometry. Replaced with the signed `Vector3.Dot(center.position - yaw.position, projectedForward)`, which preserves positive front-mount behavior but correctly moves backward/side-mounted centers beyond the conservative whole-hull radial bound. Added a real original Wasteland enemy scene regression to existing `RRLW6SawPhysicalTests.WastelandEnemySawPhysicalDiscClearsOwnHullAcrossYaw`: deliberately place actual muzzle 0.4m behind yaw, call unchanged private helper under Unity via reflection, require signed forward clearance beyond actual existing collider radial bound plus blade radius. No duplicate weapon component, garage validator or damage bypass. **AUTHORED, NOT_RUN in Unity**; native 4/4 W6 EditMode and 21/21 WPN005 PlayMode + Windows Player visual/AI/damage still mandatory, potentially failed geometry will HOLD acceptance.

## W33 motor-safety hotfix — stopped rotor vs slow coasting (native NOT_RUN)
Previous W28 owner-block handling disabled engine power/cutting by running `RotarySawMotor.Tick(false, ...)`, but its deceleration is gradual. When an owned armor part ENTERED an already spinning disc, RPM could remain high even though no new damage/energy was allowed. W33 adds `motor.StopImmediately()` only on the existing `OwnGeometryBlockedLastTick` safety path before normal motor tick. Keeps existing motor request, recovery on clearance, current heat/jam states, RPM=0 on first blocked tick, no cost/HP/ID changes. The only new original WPN005 native `UnityTest`, `MovingOwnedPartStopsAlreadySpinningSawInOnePhysicsTick`, first spins at 1000 RPM with very slow normal deceleration (50 RPM/s), moves one genuine attached-Rigidbody Armor BoxCollider into the blade disc, asserts instant RPM0/no further energy/heat/damage, clears it, then checks powered physical damage/energy and RPM recovery. Original WPN005 test count is now 22 authored (NOT_RUN). Independent native Unity 6000.3.14f1 PlayMode must execute 22/22, real R3 W6 4/4, Windows Player+actual visuals before G1.

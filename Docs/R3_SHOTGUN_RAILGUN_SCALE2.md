# Shotgun i railgun ×2

Nowe egzemplarze shotguna i railguna mają dwukrotnie większe modele, fizyczną podstawę, pojedynczy port montażowy oraz 18 pól zajętych przez jedną część. Fizyczna długość lufy jest osobna dla każdego modelu: przed powiększeniem odległość od osi do wylotu wynosi 0,45 m dla shotguna oraz 0,84 m dla railguna. Właściwe pociski powstają na widocznych wylotach.

Stare zapisane egzemplarze zachowują geometrię ×1. Magazyn pokazuje wersję, a fuzja wymaga tego samego obrysu. Nie zmieniono obrażeń, amunicji ani kosztów energii. Wrogowie oraz inne typy broni nie są objęci tą zmianą.

Unity 6000.3.14f1: **20/20 celowanych testów EditMode PASS** (`shotrail_first.xml`), w tym faktyczny zakup każdego modelu, montaż, zgodność fizycznej lufy, strzał odpowiednim systemem pocisków, trafienie, zużycie amunicji i energii oraz zapis. Osobny PlayMode, ręczny Windows Player i pełna regresja: NOT RUN.

# PARTSIZE R1 known limitations (no false positives)
- Current runtime is **self-contained**, not an R3 replacement and has no real Codex integration target SHA/ACK.
- The only derived physical collider dimensions are *existing base-root procedural primitives*: .52³ and 1.07×.52×1.07. These numbers come from source, **not original mesh triangle/Collider measurement on licensed Unity**.
- The 11 non-core/non-armor non-wide part kinds are physically **UNMEASURED**. Wheel, Gun, Suspension, CrawlerTrack, Rotor/Hover, Booster and others cannot be approved based on root cube alone. Wide parts' secondary art/animation/effects are unmeasured.
- World axes and part-root pose require canonical grid-aligned Unity orientation. Parent rotated off-grid and non-unit-scale vehicle transforms are intentionally rejected. No global rescale.
- W17 hardening: native physics gate now independently queries default-scene nearby colliders by a padded `Physics.OverlapBox` per owned physical collider; missing caller inventory returns `INCOMPLETE_EXTERNAL_BROADPHASE` and a query missing its own collider returns `PHYSICS_QUERY_UNVERIFIED`. Caller boolean `completeExternalBroadphase` remains a necessary fail-closed flag, **never proof**. Queries across custom/local physics scenes, disabled colliders, trigger-only volumes and moving/swept envelopes are not certified; even static physical results still require Unity native evidence. AABB envelope bounds can reject irregular shapes with large permitted negative spaces by design.
- No typed socket registry: logical exposed faces cannot prove actual mount sockets (`TYPED_SOCKET_UNVERIFIED`); socket authority belongs to Codex/BUILD only. No validated capsule/sphere/nonconvex model swept shape; nonconvex MeshCollider not accepted. Real wheel suspension rotation and muzzle/barrel clearance need physical source measurement and separate test fixtures.
- No prefab import/Unity compilation/PlayMode/GUI/physically independent test executed on producer host (NOT_RUN). Native PlayMode tests are authored, not passed. No approval of source under G1/G2 or direct Codex handoff.

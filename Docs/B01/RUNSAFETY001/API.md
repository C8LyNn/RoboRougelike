# RUNSAFETY001 deterministic runtime API (standalone model only)
Namespace `B01.RUNSAFETY001`. `SafetyVehicleSnapshot` contains RunActive, InGarage, NextChallengeAvailable, CoreAlive, StructureConnected, FunctionalWeapon, FunctionalDrive, CanonicalCanDeploy and OtherStartBlocker. `Evaluate()` returns one of NormalVehicle / LoanerOffered / NoNextChallenge / WrongRunPhase / RunAlreadyEnded / MissingCore / UnrelatedBlocker / InvalidSnapshot.
`SafetyOwnedPart(id,role,hpPercent,purchasePrice,rebuildQuote,mounted)` protects stable part ID; quote strictly lower than purchase price. Input price is a **quote from canonical ECON**, not a hard-coded approved 65–75% discount.
`RunSafetyState(initialParts,scrap)`: `TryQueueRebuild(partId,out charged)` only if destroyed, not already queued, no active challenge; first order between real wins free, next quoted & funds required; no refund or duplicate on repeated request; pending cannot mount; destroyed part stays 0HP.
`TryBeginChallenge(encounterId,snapshot,out SafetyLease,out SafetyDecision)` issues a lease token only if real run/garage/next event and correct functional blocker; otherwise normal healthy path; repeat same encounter id forbidden.
`RecordOutcome(encounterId,victory)` accepts only active, unprocessed ID; defeat increments no victories, does not finish queue; win increments exactly once, completes pending orders queued before win, clears free-slot flag for next cycle and unmounts returning owned part. Active loaner cleared either outcome.
`MarkExternalRunEnded()` called only by canonical R1 adapter after current run-ending state; safety prototype itself **never** decides run loss. Caller must separately ensure no new Garage state after actual defeat.
`RunSafetyDemo` renders explicit TEST controls and a temporary Rigidbody primitive, with zero gameplay/save/export authority.

# RoboRougelike B01 UNIFIED RC2 — uruchomienie

Jedno wydanie: `RoboRougelike_B01_UNIFIED_RC2_Windows_x64.zip`.

1. Wypakuj **całe archiwum** do dowolnego katalogu na Windows x64.
2. Uruchom `RoboRougelike.exe`. Pozostaw obok folder danych, MonoBleedingEdge i wszystkie DLL.
3. W menu wybierz robot Light, Standard lub Heavy, a następnie **Przygotuj pojazd** lub Enter.
4. W tym samym garażu zamontuj albo napraw części. Wybierz **Następna trasa**, **Generowana arena** albo **Zamiast trasy: obrona reaktora**. Poligon służy do próby pojazdu.
5. Po zwycięstwie wybierz jeden moduł bonusowy i od zera do trzech dostępnych części przeciwników. Zatwierdź nagrody, wróć do garażu i wybierz następną aktywność. Uszkodzenia oraz odzysk korzystają z jednego modelu części.

W/S — jazda i hamowanie; A/D — skręt; mysz — celowanie; LPM — strzelanie; kółko — zoom; Escape — pauza/wznowienie. Garaż udostępnia montaż, zaznaczanie, naprawę, zdejmowanie, obrót części XYZ i obrót widoku. Alt+F4 zamyka okno.

PPM nie ma drugiej grupy broni w tym RC. Gra nie zapisuje trwale stanu wyprawy między uruchomieniami. Znany C0000005 przy automatyzowanym zamykaniu nie został uznany za naprawiony.

## Model boundary / no automatic tuning

A's DPS/TTK are **synthetic**: projectiles are treated as immediate on nominal firing time (which can make TTK exactly 0 for a 12-gun synchronized opening), with a seeded Bernoulli hit and one abstract HP target. No projectile flight time, spread, armor, sockets, target part destruction, actual aim, distance cutoff, recoil, heat, ammo, LOS, physics, AI, or reloading. Speed estimate follows only `R3VehicleAssembly.TuneChassis`'s `sqrt(originalMass/actualMass)` cap with unchanged wheels, assuming parts are still operational. It is **not** an actual speed/acceleration measurement.

B's wallet runs use invented budgets and rewards; it **never invokes actual R1 win or wallet code** and its all-gun repair bundle is a planning what-if, not `R3VehicleModel.RepairAffordable` (which can repair only what is affordable). No pricing, weapon tuning, or source change is approved by these files.

# Ciężka armata ×2

Nowo kupiona ciężka armata korzysta ze wspólnej geometrii ×2: jedna część i jedno HP, port przy podstawie, 18 pól montażowych, rzeczywisty collider oraz oddzielna przestrzeń robocza lufy. Oś importowanego modelu zmierzono w Unity w tym samym miejscu co dla podstawowego działa i Automatic. Dotychczasowe zapisane i fabryczne egzemplarze zachowują skalę ×1; magazyn pokazuje rozmiar, a fuzja wymaga zgodnego obrysu.

Unity 6000.3.14f1: 21/21 celowanych testów EditMode PASS (`heavy_scale_green.xml`), w tym zakup w garażu, realne trafienie za 100 HP i dotychczasowy koszt 2,5 energii, oba wcześniej powiększone działa i zapis. Pomiary osi dziewięciu modeli: 1/1 PASS (`all_weapon_axes.xml`). Osobny PlayMode, Windows Player i pełna regresja: NOT RUN. Pozostałe rodzaje broni i wrogowie nie są objęte tą zmianą.

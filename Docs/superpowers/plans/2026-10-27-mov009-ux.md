# MOV009 suspension UX

Goal: help a player discover, configure and understand the real suspension without changing physics or balance.

- Read the existing MOV009 adapter/controller, height limits, drive and pause state; test status against actual installed, damaged, disabled and hover conditions.
- Introduce read-only presentation of selected mode, requested height, functional modules and current force; never report force from stale pause or hover state.
- Explain installation, mode differences and height in the existing garage panel; expose accurate status and enabled/disabled controls in pause and battle telemetry.
- Regression-test garage rebuilding, groups, map editor, camera and pause; build and exercise Windows Player without controlling the desktop; document visual/manual limitations.

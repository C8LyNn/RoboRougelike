# Duże koło terenowe: obrys montażowy

Nowo kupione duże koło terenowe rezerwuje 3 × 3 pola w płaszczyźnie opony, wraz z obrotem. Jest jedną częścią z jednym HP i portem mocowania przy osi. Promień fizycznej opony wynosi 0,56 m; fizyka i przyczepność nie zostały zmienione. Podgląd i walidacja korzystają z tego samego obrysu.

Wcześniej zapisane koła zachowują istniejący jednopólkowy obrys i identyfikator. Stare i nowe warianty nie łączą się podczas fuzji. Pozostałe modele wymagają osobnego dostosowania do własnej geometrii. Wizualny odbiór w Windows Playerze i pełna regresja pozostają do wykonania.

Celowane testy Unity 6000.3.14f1 EditMode: 18/18 PASS (`large_footprint_green.xml`), obejmujące oba większe koła, montaż, fizyczne przejazdy i odczyt zapisu. PlayMode i Windows Player: NOT RUN.

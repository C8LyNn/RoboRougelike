## New real working storage boundary, #666 authorized

`SingleFileSaveSlot.cs` is a NEW independent B01-62-owned C#9/.NET8 source-backed reference, NOT an alternative R4 Unity MonoBehaviour. It stores ONE authoritative file `save.envelope` containing: magic+schema version; **RunId**, **slot GUID**, **monotonic generation**, **length**, **unchanged frozen #556 SnapshotCodec binary** and full-envelope SHA-256. It does not write an independent checkpoint sidecar and therefore avoids the unsynchronized two-file snapshot/checkpoint commit of the previous isolated bridge. `TryCommit` validates true original frozen #556 `ColdRestore.TryStage`, ID/RunId and expected generation, stages a newly generated exclusively owned `pending-UUID.stage` in the **same directory**, writes with `FileOptions.WriteThrough`+`FileStream.Flush(true)`, reads back, and invokes one `File.Move(stage,final,overwrite:true)` publication boundary. It then verifies the published file and original binary bytes. Callers have one epoch authority, not two separate CAS sources. On any exception after publication is attempted (including actual renamed file, lost ACK) it immediately and persistently **quarantines this in-memory owner**, blocks all further reads/Save/Load, preserving forensic files. New owner with the SAME original run+slot after the previous owner lease closes opens the actual finalized file, verifies checksum/original codec and resumes only from persisted generation. Never adopt a `pending-*.stage` file on recovery; do not promote stale speculative writes, do not delete original files, previous snapshots, empty dirs or user saves.

`TryCreateNew` refuses *any* occupied path including alien **EMPTY** directory (does not delete it); `TryOpenExisting` enforces exact original owner marker identity. A retained OS `FileShare.None` `slot.lease` stops parallel processes and concurrent logical hosts from holding the same slot simultaneously. After Dispose, old writer returns Closed; a new process can reopen and advance the actual final generation. Foreign run/GUID, nonconsecutive generations, same-gen fork, modified canonical file and invalid original frozen codec fail closed. This is directly runnable OS code with actual independent child CLR process contention, not a mocked database.

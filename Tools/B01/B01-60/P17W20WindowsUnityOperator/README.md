# B01-60 — PASS 17 / WAVE 20 | Windows local Unity 6000.3.14f1 operator (#667)

**SCOPE:** One manually operated local Windows action. Does **not** connect to your PC via SSH. Does **not** install Unity, activate/license Unity, fetch from GitHub, create any privileged background service, modify your game checkout or push/merge/auto-upload anything. Builds a *new* GUID-named detached Git clone **outside the game folder**, performs source-only checks, and optionally runs genuine Unity. Retains its own scratch/evidence for manual inspection; **never recursively deletes** any directory, symlink, foreign file or original player saves.

## One-line Windows command, operator opt-in

Prerequisites: locally installed Git, Python 3, Windows PowerShell 5.1 or PowerShell 7, Unity Hub installed **6000.3.14f1** Editor with legitimately activated license (for native), and an existing B01 Git checkout **containing this W20 branch/PR exact code** plus all frozen Git source objects. A normal source preflight does **not** require Unity license. Open PowerShell **at the root of your existing RoboRougelike checkout**:

```powershell
pwsh -NoProfile -File .\Tools\B01\B01-60\P17W20WindowsUnityOperator\Invoke-B0160WindowsUnity.ps1 -RepoPath . -Run
```

The script checks the source, creates a new local disposable clone, reports its absolute scratch folder, checks Unity Test Framework and physics package declarations, probes the standard Unity Hub executable `C:\Program Files\Unity\Hub\Editor\6000.3.14f1\Editor\Unity.exe`, hashes the executable and then asks you to type **`B0160 RUN NATIVE`** to confirm a single real run. **Without your typed confirmation it does not launch Unity.** To perform source-only preflight without Unity or confirmation, omit `-Run`. If using Windows PowerShell 5.1 instead of PowerShell 7, replace `pwsh` with `powershell`. If `Unity.exe` is installed at a different location, supply `-UnityPath 'C:\...\6000.3.14f1\Editor\Unity.exe'` (the version directory is strictly checked).

## Isolation and provenance

- Before any work, the script ensures this PowerShell file matches its exact tracked Git HEAD blob, source Git HEAD is recorded, and the existing original #532 native script is present. A local-only `git clone --no-hardlinks --no-checkout` creates a **fresh GUID-specific scratch** under `%TEMP%` or explicitly supplied `-ScratchParent`, with hooks disabled, detached at the exact original SHA. It refuses a scratch parent inside or containing the original game workspace, and refuses a reparse-point/symlink scratch parent.
- In the scratch clone, verifies `ProjectVersion.txt`, `com.unity.test-framework`, and `com.unity.modules.physics`. Python source preflight actually stages a source-only ZIP with original source SHA/Unity `.meta` GUIDs, negative tamper tests, and receipt. Python temporary native stage directories are forced into **only the new scratch**.
- After explicit opt-in, **real activated Unity executable** runs original `-batchmode -runTests` for EditMode and PlayMode/PhysX. Source-lock and exact original NUnit XML/Editor.log verification come from the previously verified and unchanged runner. Native result and all original logs remain on the operator's computer. Missing executable/licensing/XML/uncertain test status => fail-closed, native **NOT_RUN/FAIL**, never fabricated G1.
- Locally retained `evidence/operator-report.json`, immutable original `receipt.json`, actual `*-process.txt`, `EditMode.xml`, `PlayMode.xml`, real `*-Editor.log` if created, plus **`sha256-manifest.json`** and its own SHA256 fingerprint. These are **integrity hashes, not a cryptographic signature** (no key available and no claim of Authenticode signing). Start/end times, source SHA, Unity binary SHA256 and source/native status recorded; process exit codes retained in the original process files. No automatic upload. Unity Editor logs can contain computer-specific paths, so inspect/redact before manually sharing evidence.
- Zero recursive cleanup even on failure; the owner may manually inspect the **GUID-named folder created by the script**. Never ask B01-60 to delete a shared folder or alter your real `Application.persistentDataPath`. If activation fails, keep the evidence and choose `NOT_RUN`.

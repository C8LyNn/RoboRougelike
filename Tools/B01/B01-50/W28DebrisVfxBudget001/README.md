## Player-facing effect / criteria
- Destruction of robot module causes `R3Debris.Separated` -> only the fastest opt-in cosmetic debris emit short trailing sparks, up to configurable budget. New detachment automatically participates without prefab rewiring; no impact on shot path or detaching modules' real physics.
- Explicitly disable or remove controller: all emitters the controller tracks stop, but actual debris continues flying/rolling/colliding, still subject to original game 70-cap/10-second lifecycle. Invalid configuration is rejected.
- If >16 debris are fast, only 16 produce sparks. If previously fast debris slows, a different eligible debris can receive the visual slot on subsequent refresh. No new emitter is created for any body not observed via genuine `R3Debris.Separated`.
- Dynamic obstacles, 500 detached cubes from old #818 and active attached vehicle parts are NOT implicitly eligible; only real original R3 detached non-kinematic bodies are observed. No false claim of a measurable FPS improvement — VFX allocations/CPU/GPU/GC need native profiling.

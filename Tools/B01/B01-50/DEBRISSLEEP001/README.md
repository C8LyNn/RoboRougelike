# B01-50 · DEBRISSLEEP-001/R1 · PASS 17 / WAVE 23

## Product functionality
A **real opt-in Unity 6000.3.14f1-facing Rigidbody Sleep() governor** for **cosmetic detached debris only**, not a gameplay subsystem and not a standalone dummy harness. It asks Unity physics to sleep a selected body's Rigidbody only after 8..600 consecutive quiet FixedUpdate steps (default 60) under both linear and angular speed thresholds (defaults 0.08 m/s and 0.10 rad/s). It does not change Physics settings, mass, colliders, velocity, gravity, transforms, joint state or health. Collision Enter and Exit reset quiet eligibility. The policy submits **at most one sleep request per quiet interval**; if Unity rejects Sleep because an awake Rigidbody is touching the debris, it does not hammer repeated calls. A genuinely observed IsSleeping() state re-arms policy for a later new quiet window after the native engine wakes the object. The native engine retains physical contact wake-up authority; this package never calls WakeUp() during OnDisable.

**Important: Unity already auto-sleeps low-energy bodies.** DEBRISSLEEP may yield **zero or negative net benefit** because its own FixedUpdate and GetComponent<Joint> checks consume CPU. There is **no verified native frame-time, GC, solver-body-count or GPU improvement**. An actual license-activated representative PhysX benchmark is required before optimization acceptance. This is an opt-in experimental feature, not an unconditional efficiency recommendation.

## Anti-gameplay constraints
- `allowCosmeticSleep` is serialized **false by default**. It is captured/validated only during Awake; a late script cannot arm a component that did not consent at initialization.
- Only disposable, independent decorative rigidbodies. Never install on player, enemy, vehicle chassis/modules, weapon, objective, moving cargo, puzzle, mobility-critical part, mission trigger, essential light or any retained gameplay state. Refuse a locally jointed Rigidbody (checks at Awake and each tick), kinematic rigidbodies and those with collision detection disabled. No global scans.
- Fail closed on invalid/NaN/Infinity initial speed/cadence, or runtime velocity NaN/Infinity, and on disabled/destroyed state. Threshold/cadence values are frozen after successful Awake: Inspector drift cannot escalate the budget mid-session. Actual `allowCosmeticSleep=false` at runtime stops future requests.
- One governor per selected body; unrelated bodies never share counters. OnDisable resets policy without waking the object, and OnDestroy irreversibly retires the policy. No automatic persistent data, no save/load, no per-frame logging, no event upload, no network/credentials, no interaction with canonical R5 host or Save/Load.
- The local Joint check is not a complete proof that the body is safe gameplay-wise: cross-object constraints, scripts and parent objects are the operator's responsibility. This is an experimental tool and cannot be integrated without human review.

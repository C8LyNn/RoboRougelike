- `OnCollisionStay` checks actual Unity `Collision.body` (Rigidbody OR ArticulationBody). When non-null, reset the quiet window just like R2 for any moving/kinematic or temporarily still other physical body. When null, treat **static no-body Collider** Stay as a resting support and permit the existing measured low linear/angular speed window. This follows official Unity 6000.x Collision.body docs: https://docs.unity.cn/2023.3/Documentation/ScriptReference/Collision-body.html . A static collider illicitly moved through Transform without a Rigidbody can still move: the scheme does NOT declare it safe or authoritatively classify all scene motion; actual native collision QA and author review required.
- Defer `GetComponent<Joint>()` from every FixedUpdate to the **single moment the unchanged pure policy requests Sleep**. Joint validity is STILL checked on Awake and immediately before every actual request, including dynamically attached joints. If a joint appears, discard the entire quiet interval without invoking `Sleep()`; do not disable or alter the joint, body's velocity, gravity, collider, contact or transform. Original pure `Core/DebrisSleepPolicy.cs` Git blob `6f407626639e68add97cd3d2e75c7d64a505fe6a` is BYTE IDENTICAL to prior R1/R2. The only functional change is optional visual debris physics under explicit consent.
- Invalid settings, disabled/retired/kinematic/no-collision guard, explicit consent, collision Enter/Exit reset, lifetime lease, request-limit/cooldown, natural PhysX wake and independent bodies are unchanged from source-tested R2.

The governor is an experimental *candidate*; it may be redundant or slower, and **no native CPU frame-time, solver load, GC, FPS or GPU improvement has been measured**. Its additional code can impose overhead. No placement on gameplay-critical player/enemy rigs, detachable **owned** parts, weapons, loot, goals, mobile props, puzzles, mission triggers or Save/Load world assemblies.

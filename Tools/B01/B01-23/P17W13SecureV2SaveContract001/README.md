## Binary schema and trust contract

Little-endian deterministic B01SRV2SAVE schema 1 (`B0123SL1` magic), exact immutable candidate source SHA (40 ASCII bytes), 16-byte run UUID, signed 64-bit generation/anti-rollback sequence, pending-transaction flag (MUST be false), exactly 2 sorted part rows. Each row: original stable long ID, persistent **module GUID** (not Unity .meta GUID), detached/consumed/kinematic flags, position (3 doubles), unit quaternion (4 doubles), linear velocity (3 doubles), angular velocity (3 doubles), local mount (3 doubles). Whole payload sealed with SHA-256 to reject corrupt writes/partial files (integrity, **not authenticity or an HMAC**). Strict fixed-size and byte flag encodings, rejects trailing bytes, old/unknown schema, mismatched source SHA, different run GUID, rollback generation, duplicate/missing/reordered/foreign IDs or GUIDs, inconsistent detached/consumed/kinematic state, invalid/nonfinite/unbounded pose, invalid quaternion and wrong mount. Fixtures map known frozen original `SecureRigCatalog` ID 2310001 and 2310002 to **illustrative trusted GUID registry**; an authorized game integration must store its own persistent GUID registry across saves and never regenerate GUID at load.

**Restoration order, fail closed:** freeze active detach/dock/reset/save, never capture while busy; load/save byte validation+checksum+candidate source+run+epoch+trusted part GUID registry first, verify all records, then create entirely NEW **original** `AtomicDockLedger` per rig in an isolated staging container, consume exactly the detached IDs via original W06 zero-impulse detach (never apply a physical force while loading), assert attached unconsumed and detached consumed, and only after success propose whole-world offstage physical reconstruction. **Current frozen #510 has NO public operation to atomically swap its private ledgers and physics rigs:** therefore `PreparedRestore` is **only an immutable validated plan plus staged real ledgers**, never performs live Rigidbody/Transform changes; `UNITY_SAVELOAD_APPLY=HOLD`. Future separate approved version/adapter must implement safe main-thread fresh-world swap with pre-swap rollback, matching GUID registry, scene/prefab exclusion of legacy W07/#511/#494 and no #510 source rewrite. If save/load starts during `AtomicDockLedger.Busy` or a detach/dock/reset command, refuse rather than mutate any state.

**Atomic save file transport (receiver responsibility):** write new save bytes in a same-volume temp file, fsync file, verify checksum, atomically rename/replace per platform, fsync directory if supported. Never overwrite the current save until new validated bytes are durable. On load, keep old scene+ledger unchanged until a new complete state is built and verified; fail entirely if any record or scene preflight fails. Do not delete unknown/foreign files/empty directories when rolling back temporary work. B01-40/62 own stage/rollback wrapper and are separately testing the original #510 foreign-empty-dir problem. This contract neither alters nor claims that rollback is fixed.

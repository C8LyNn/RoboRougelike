## Real installation, without touching game source

The tool **refuses** to write unless the target is outside any Git checkout and **explicitly** marked as a disposable project. It never marks a real Codex project on its own. Construct a separate throwaway folder with `Assets/` and marker whose UTF-8 file has exact text `B0140-P17W02-DISPOSABLE-UNITY-STAGING v1\n` (with the final newline). For example, on Linux:

```bash
git fetch --no-tags --depth=1 origin be2c4b6ac63e04eff5b046e50641ec8d1da4837f
mkdir -p /tmp/b0140-disposable-only/Assets
printf 'B0140-P17W02-DISPOSABLE-UNITY-STAGING v1\n' > /tmp/b0140-disposable-only/.b0140-disposable-only
python Tools/B01Validation/P17W02/disposable_sprite_stage.py --repo . --archive /path/to/extracted/B0140-PartDamageDecals-UnitySpriteSingles.zip --project /tmp/b0140-disposable-only --mode preflight
python Tools/B01Validation/P17W02/disposable_sprite_stage.py --repo . --archive /path/to/extracted/B0140-PartDamageDecals-UnitySpriteSingles.zip --project /tmp/b0140-disposable-only --mode install
python Tools/B01Validation/P17W02/disposable_sprite_stage.py --repo . --archive /path/to/extracted/B0140-PartDamageDecals-UnitySpriteSingles.zip --project /tmp/b0140-disposable-only --mode verify
python Tools/B01Validation/P17W02/disposable_sprite_stage.py --repo . --archive /path/to/extracted/B0140-PartDamageDecals-UnitySpriteSingles.zip --project /tmp/b0140-disposable-only --mode rollback
```

A successful test physically writes and verifies **27 actual importer files under `Assets/B01ImportStaging`** (12 PNG +12 PNG meta +3 folder meta), then removes only these paths. It writes its machine-readable receipt `.b0140-p17w02-install-receipt.json` outside Assets and refuses rollback if the receipt, original bytes, staged directory structure or foreign files have changed. Unrelated `Assets/` files are retained; no overwrite; symlinks, Git worktrees, case-insensitive path aliases and lack of marker are rejected. A modified staged file or extra foreign file/empty subdirectory causes rollback to **STOP WITHOUT DELETING IT**.

The exact scripts run the whole workflow against the actual original ZIP on both Ubuntu 24.04 and Windows 2025 using GitHub Actions artifact download (the **same** binary) and produce a receipt plus a physical rollback proof. Native Unity is **NOT RUN**, so these checks do **not** establish actual prefab/sprite importer success or visible URP part overlays.

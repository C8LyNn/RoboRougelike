# RoboRougelike — komplet referencji graficznych (2026-11-12)

Zawartość: 10 unikalnych plansz koncepcyjnych PNG, 5 stylów × 2 iteracje (wczesna i High Detail).

**Ważne:** są to wygenerowane ilustracje art-direction, a nie gotowe modele 3D ani geometrycznie zgodne projekty mechaniczne. Nie kopiuj dosłownie siatek, proporcji kolizji lub konstrukcji, które nie mieszczą się w istniejącym kontrakcie R4. Modeluj autorskie assety spełniające zasady budowania.

## Które traktować jako główne?

- 06_A_Sleek_Futuristic_HighDetail.png — główna: premium, płynne wielowarstwowe osłony, wnętrza, subtelne cyan glow.
- 07_B_Brutal_Industrial_HighDetail.png — główna: ciężkie metalowe ramy, hydraulika, mechaniczne połączenia.
- 08_C_Arcade_Geometric_HighDetail.png — główna: oszczędne detale, mocna geometria i profesjonalne proporcje, nie placeholder.
- 09_D_Scrap_Wasteland_HighDetail.png — główna: realistyczne PBR, złom, spawy i zużycie zależne od geometrii.
- 10_E_Heroic_Toon_HighDetail.png — główna: miękka stylizacja, wyraziste kształty i wysokiej jakości toon look-dev.

Obrazy 01–05 to wcześniejsza iteracja referencji dla tych samych stylów; wykorzystuj je jako pomocnicze.

## Zasady dla Fable

1. Każdy styl ma mieć osobny design form, materiałów, wykończeń, proporcji i animacji, nie tylko paletę barw.
2. Oceniamy oddzielnie jakość neutralnych modeli i prezentację w oświetleniu. Nie uznawaj oświetlenia jako substytutu geometrii.
3. Zawsze sprawdzaj ograniczenia obrysu, pivotów, portów, kolizji, animacji i blueprintów R4.
4. W razie konfliktu referencji z kontraktem gameplayowym dokumentuj ograniczenie i alternatywę; nie zmieniaj mechaniki.
5. Warianty High Detail są wzorcem jakości wizualnej, nie wymaganiem kopiowania nadmiaru trójkątów lub VFX.
